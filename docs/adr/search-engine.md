Сравнение поисковых API Google и Yandex по заданным критериям показывает, что выбор зависит от вашего статуса как разработчика и целевого рынка. Google предлагает мощную экосистему, но имеет критические ограничения по доступности, а Yandex ориентирован на российский рынок с более сложной, но гибкой системой тарификации.

### Пояснения по критериям

**Стоимость запроса**
*   **Google**: Стоимость составляет **$5 за 1000 запросов** после бесплатных 100 запросов в день. Однако API **закрыт для новых клиентов**, и его поддержка прекратится 1 января 2027 года .
*   **Yandex**: Тарифы сложнее. Есть бесплатный ночной лимит (1000 запросов/мес), далее цена зависит от времени суток . Асинхронный режим может снизить стоимость до **~25-30 руб. за 1000 запросов** .

**Суммаризация средствами LLM**
*   **Google**: Существуют готовые MCP-серверы (например, `mcp-google-custom-search`), которые предоставляют инструмент для получения **суммированного ответа (markdown summary)** на основе результатов поиска .
*   **Yandex**: Также доступны MCP-серверы, которые поддерживают как обычную выдачу, так и **AI-генерированные ответы (через модель Yazeka)** . Это делает оба варианта удобными для интеграции с LLM.

**Доступность из России**
*   **Google**: Критическое ограничение. API **недоступен для новых пользователей** и полностью прекратит работу в начале 2027 года . Это делает его неприемлемым для новых проектов.
*   **Yandex**: **Полностью доступен** для резидентов РФ и интегрирован в Yandex Cloud. Аутентификация проста (API-Key), а сервис официально поддерживает российский рынок .

## Решение 

Для новых проектов, особенно ориентированных на Россию, **Yandex Search API является безальтернативным выбором** из-за недоступности Google.
