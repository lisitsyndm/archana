# Описание инструментов системы Archana

Данный документ содержит описание всех инструментов, реализованных в директории `tools`. Каждый инструмент представляет собой команду, наследуемую от `Command`, и может быть вызван как скилл или через свободный текст.

---

## context.py

Инструменты для управления контекстом диалога и переменными.

### Покажи весь контекст

**Описание:** Выводит текущее состояние контекста — название контекста и все сохранённые переменные.

**Пример использования (скилл):**
```
/ Покажи весь контекст
```

**Пример использования (свободный текст):**
```
Покажи текущий контекст
```

---

### Создай новый контекст

**Описание:** Создаёт новый пустой контекст с указанным названием, заменяя текущий контекст.

**Пример использования (скилл):**
```
/ Создай новый контекст : {"text": "Новый проект"}
```

**Пример использования (свободный текст):**
```
Создай новый контекст для проекта по анализу данных
```

---

### Покажи последний результат

**Описание:** Выводит текст последнего выполненного результата операции.

**Пример использования (скилл):**
```
/ Покажи последний результат
```

**Пример использования (свободный текст):**
```
Что было в последний раз?
```

---

### Покажи переменную

**Описание:** Выводит значение именованной переменной из контекста.

**Пример использования (скилл):**
```
/ Покажи переменную : {"name": "результат_поиска"}
```

**Пример использования (свободный текст):**
```
Покажи переменную результат_поиска
```

---

### Покажи список переменных

**Описание:** Выводит список всех именованных переменных, сохранённых в текущем контексте.

**Пример использования (скилл):**
```
/ Покажи список переменных
```

**Пример использования (свободный текст):**
```
Какие переменные у меня есть?
```

---

### Запомни последний результат как

**Описание:** Сохраняет текст последнего результата под указанным именем в переменную контекста.

**Пример использования (скилл):**
```
/ Запомни последний результат как : {"name": "итог_анализа"}
```

**Пример использования (свободный текст):**
```
Запомни последний результат как итог_анализа
```

---

### Запомни текст как

**Описание:** Сохраняет произвольный текст под указанным именем в переменную контекста.

**Пример использования (скилл):**
```
/ Запомни текст как : {"name": "заметка", "text": "Важная информация для проекта"}
```

**Пример использования (свободный текст):**
```
Запомни текст как заметка, текст: Важная информация для проекта
```

---

### Добавь к переменной

**Описание:** Добавляет текст последнего результата к существующей переменной или создаёт новую, если переменная не найдена.

**Пример использования (скилл):**
```
/ Добавь к переменной : {"name": "заметка"}
```

**Пример использования (свободный текст):**
```
Добавь к переменной заметка
```

---

### Подставь переменные в последний результат

**Описание:** Заменяет плейсхолдеры переменных `<@ имя_переменной @>` в последнем результате на их фактические значения.

**Пример использования (скилл):**
```
/ Подставь переменные в последний результат
```

**Пример использования (свободный текст):**
```
Подставь все переменные в результат
```

## database.py

Инструменты для работы с базой данных PostgreSQL.

### Найди в БД

**Описание:** Выполняет поиск информации в базе данных по ключу (имени).

**Пример использования (скилл):**
```
/ Найди в БД : {"query": "документ_123"}
```

**Пример использования (свободный текст):**
```
Найди в базе документ_123
```

---

### Сохрани в БД

**Описание:** Сохраняет информацию в базу данных под указанным ключом. При наличии ключа обновляет существующую запись.

**Пример использования (скилл):**
```
/ Сохрани в БД : {"name": "отчет_2024", "text": "Итоговый отчет за 2024 год"}
```

**Пример использования (свободный текст):**
```
Сохрани в базу отчет_2024: Итоговый отчет за 2024 год
```

## researcher.py

Инструменты для поиска информации в интернете.

### Найти в интернете

**Описание:** Выполняет поиск информации в интернете с помощью Yandex API и возвращает содержимое найденных страниц.

**Пример использования (скилл):**
```
/ Найти в интернете : {"text": "последние новости искусственного интеллекта 2024"}
```

**Пример использования (свободный текст):**
```
Найди в интернете последние новости об искусственном интеллекте
```

## plan.py

Инструменты для управления планами выполнения.

### Выполни план

**Описание:** Запускает выполнение текущего плана с начала.

**Пример использования (скилл):**
```
/ Выполни план
```

**Пример использования (свободный текст):**
```
Начни выполнять план
```

---

### Удали план

**Описание:** Сбрасывает текущий план, готовит систему к выполнению плана с начала.

**Пример использования (скилл):**
```
/ Удали план
```

**Пример использования (свободный текст):**
```
Удали текущий план
```

---

### Продолжи выполнение плана

**Описание:** Продолжает выполнение приостановленного плана с текущего шага.

**Пример использования (скилл):**
```
/ Продолжи выполнение плана
```

**Пример использования (свободный текст):**
```
Продолжи выполнение плана
```

---

### Останови выполнение плана

**Описание:** Приостанавливает выполнение текущего плана.

**Пример использования (скилл):**
```
/ Останови выполнение плана
```

**Пример использования (свободный текст):**
```
Останови выполнение плана
```

---

### Загрузи план из базы данных

**Описание:** Загружает план из базы данных по указанному названию.

**Пример использования (скилл):**
```
/ Загрузи план из базы данных : {"name": "исследование_рынка"}
```

**Пример использования (свободный текст):**
```
Загрузи план из базы данных исследование_рынка
```

---

### Сохрани план в базу данных

**Описание:** Сохраняет текущий план в базу данных под указанным названием.

**Пример использования (скилл):**
```
/ Сохрани план в базу данных : {"name": "исследование_рынка"}
```

**Пример использования (свободный текст):**
```
Сохрани план в базу данных исследование_рынка
```

---

### Сохрани последнюю команду в план

**Описание:** Добавляет последнюю выполненную команду в текущий план.

**Пример использования (скилл):**
```
/ Сохрани последнюю команду в план
```

**Пример использования (свободный текст):**
```
Добавь последнюю команду в план
```

---

### Покажи план

**Описание:** Выводит содержимое текущего плана — список команд с их параметрами.

**Пример использования (скилл):**
```
/ Покажи план
```

**Пример использования (свободный текст):**
```
Что у нас в плане?
```

## unclassified.py

Инструменты для обработки произвольного текста с помощью LLM.

### Вызов LLM

**Описание:** Отправляет произвольный текст (промпт) в LLM и возвращает ответ нейросети.

**Пример использования (скилл):**
```
/ Вызов LLM : {"text": "Проанализируй данный текст и выдели основные тезисы"}
```

**Пример использования (свободный текст):**
```
Проанализируй данный текст и выдели основные тезисы
```

---

## search.py (DEPRECATED)

Устаревший инструмент поиска. Не используется в текущей версии.

## init_tools.py

Файл инициализации. Не содержит инструментов, только функцию `initTools()`, которая регистрирует все доступные инструменты в контексте.
