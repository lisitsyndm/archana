# Метрики

Перечень экмпортируемых метри содержится в файле observability/metrics.py

## Перечень настроенных метрик

| Название метрики | Тип | Описание                                                                        |
|------------------|-----|---------------------------------------------------------------------------------|
| process_command_total | Counter | Общее количество выполненных команд (вызовов инструментов)                      |
| process_command_duration_seconds | Histogram | Длительность выполнения команд (вызовов инструментов)                           |
| llm_classification_duration_seconds | Histogram | Длительность LLM-классификации сообщений пользователя                           |
| llm_data_prep_duration_seconds | Histogram | Длительность подготовки данных для инструментов с помощью LLM                   |
| llm_inference_command_duration_seconds | Histogram | Длительность LLM-инференса, не связанного с классификацией и подготовкой данных |
| llm_tokens_total | Counter | Количество потраченных токенов LLM                                                  |

## Настрока observability

В связи с известной ошибкой настройка Observability осуществляетя в ручном режиме.

После развертывания приложения необходимо вручную через UI Grafana добавить источник данных Prometheus:

```
http://prometheus:9090
```

Через UI Grafana установить дашборд "LLM".
Дашборд находится тут: `observability/llm-dashboards.json`

# Журналирование

В связи с тем, что взаимодействие с приложением осуществляется через консоль,
журнал по умолчанию выводится в файл. Адрес файла задается в переменной окружения `LOG_PATH`.

Для просмотра журнала можно использовать команду

```
docker exec -it archana_app sh
cat app.log
```

для выхода из командной строки контейнера нужно выполнить команду `exit`.
