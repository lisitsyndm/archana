# Archana: ИИ-Ассистент архитектора

Учебный проект на курсе ИИ-архитектор.
ИИ-агент, обеспечивающий возможность более детального управления
планами и контекстом.

Постановка задачи: [prd.md](docs/prd.md)

Общее описание: [arch.md](docs/arch.md)

## Установка и запуск

По умолчанию проект предназначен для установки на локальной машине.

### Пререквизиты

* Установленный и настроенный Docker Compose
* Наличие доступа к LLM
* Наличие доступа к Yandex AI Studio (Search API)

### Подготовительные действия

* Определите переменные окружения в файле `.env`, в том числе:
  * Реквизиты доступа к LLM,
  * Реквизиты доступа к Yandex AI Studio (для поиска в Интернете)

### Установка

```bash
deploy.ps1
```

Если запуск скриптов заблокирован на локальном компьютере,
выполните следующую последовательность команд:

```bash
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
.\deploy.ps1
```

## Работа с приложением

По умолчанию приложение уже запущено работает в контейнере `archana_app`.
Взаимодействие с приложением осуществляется через консоль.
Подключиться к консоли контейнера можно командой:

```bash
docker attach archana_app
```

Возврат к консоль

```bash
Ctrl + P Ctrl + Q
```

При завершении работы основного приложения его можно повторно запустить командой

```bash
docker start archana_app
```
