# План: Переместить `self.Commands` из `ContextRoot` в `CommandProcessor`

## Контекст

- `ContextRoot.Commands: List[Command] = []` — список команд, хранящийся в `ContextRoot`
- `CommandProcessor` использует `self.ctx_root.Commands` в методах `_find_command()` и `_classify()`
- `initTools(ctx: ContextRoot)` и все `Register*Commands(ctx: ContextRoot)` функции принимают `ContextRoot` и добавляют команды через `ctx.Commands.append(...)`
- `main.py` и все тесты создают `ContextRoot`, затем `CommandProcessor(ctx_root)`, затем вызывают `initTools(ctx_root)`

## Изменения

### 1. `core/context_root.py`
- Удалить строку `self.Commands: List[Command] = []` из `__init__`
- Удалить импорт `Command` (если больше не используется)

### 2. `core/command_processor.py`
- В `__init__`: добавить `self.Commands: List[Command] = []`
- В `_find_command()`: заменить `self.ctx_root.Commands` → `self.Commands`
- В `_classify()`: заменить `self.ctx_root.Commands` → `self.Commands`

### 3. `tools/init_tools.py`
- Изменить сигнатуру: `def initTools(cp: CommandProcessor)`
- Внутри вызывать `Register*Commands(cp)` вместо `Register*Commands(ctx)`
- Добавить импорт `CommandProcessor`

### 4. Все `tools/Register*Commands` функции (8 файлов)
Изменить сигнатуру с `ctx: ContextRoot` на `cp: CommandProcessor`:
- `tools/context.py` — `RegisterContextCommands`
- `tools/controls.py` — `RegisterControlCommands`
- `tools/database.py` — `RegisterDatabaseCommands`
- `tools/file_system.py` — `RegisterFileCommands`
- `tools/plan.py` — `RegisterPlanCommands`
- `tools/researcher.py` — `RegisterResearcherCommands`
- `tools/search.py` — `RegisterSearchCommands`
- `tools/unclassified.py` — `RegisterUnclassifiedCommands`

В каждой функции заменить `ctx.Commands.append(...)` → `cp.Commands.append(...)`

### 5. `main.py`
- Изменить: `initTools(ctx_root)` → `initTools(service.CommandProcessor)`
  (или: создать `CommandProcessor` первым, передать его в `initTools`, затем передать в `MessageService`)

### 6. Тесты (4 файла)
Изменить порядок инициализации в каждом тестовом классе:
- `test_context.py`, `test_database.py`, `test_filesystem.py`, `test_researcher.py`
- Создать `ctx_root = ContextRoot()` → `cmd_processor = CommandProcessor(ctx_root)` → `initTools(cmd_processor)`
- Классовые атрибуты заменить на экземпляры в `setUp`
