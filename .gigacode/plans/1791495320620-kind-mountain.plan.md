# План: Перемещение embedder_client.py и llm_client.py в папку llm

## Задача
Переместить `core/embedder_client.py` и `core/llm_client.py` в новую папку `core/llm/`, обновив все импорты.

## Шаги

### 1. Создать папку `core/llm/`
- Создать директорию `core/llm/`
- Создать пустой файл `core/llm/__init__.py`

### 2. Переместить файлы
- `core/embedder_client.py` → `core/llm/embedder_client.py`
- `core/llm_client.py` → `core/llm/llm_client.py`

### 3. Обновить импорты

| Файл | Старый импорт | Новый импорт |
|------|--------------|--------------|
| `core/command_processor.py` | `from core.llm_client import LLMClient` | `from core.llm.llm_client import LLMClient` |
| `tools/database.py` | `from core.embedder_client import EmbedderClient` | `from core.llm.embedder_client import EmbedderClient` |
| `tools/unclassified.py` | `from core.llm_client import LLMClient` | `from core.llm.llm_client import LLMClient` |

### 4. Очистить кэш
- Удалить `__pycache__` файлы для затронутых модулей:
  - `core/__pycache__/embedder_client.cpython-*.pyc`
  - `core/__pycache__/llm_client.cpython-*.pyc`

## Верификация
- Запустить `python -c "from core.llm.llm_client import LLMClient; from core.llm.embedder_client import EmbedderClient"` для проверки импортов.
