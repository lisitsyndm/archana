# План: Добавление семантического поиска с эмбеддингами в pgvector

## Цель
Реализовать сохранение эмбеддингов и семантический поиск данных в таблице `knowledge`.

## Выбранные параметры
- **Модель эмбеддингов:** `text-embedding-3-small` (через aitunnel.ru API)
- **Поиск:** семантический (cosine similarity `<=>`)
- **Метрика:** косинусное сходство

## Файлы для изменения

### 1. `migrations/db_0000.py` — Добавить столбец embedding
- Добавить столбец `embedding vector(1536)` в таблицу `knowledge`
- 1536 — размерность векторов модели `text-embedding-3-small`

```sql
ALTER TABLE knowledge ADD COLUMN IF NOT EXISTS embedding vector(1536);
```

### 2. `tools/embeddings.py` — Новый модуль для генерации эмбеддингов
Создать утилиту для генерации эмбеддингов через OpenAI API:

```python
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

def generate_embedding(text: str) -> list[float]:
    """Генерирует эмбеддинг текста через OpenAI API."""
    client = OpenAI(
        api_key=os.getenv("LLM_APIKEY"),
        base_url=os.getenv("LLM_URL", "https://api.aitunnel.ru/v1/")
    )
    response = client.embeddings.create(
        model="text-embedding-3-small",
        input=text
    )
    return response.data[0].embedding
```

**Зависимость:** добавить `openai` в `requirements.txt`

### 3. `tools/database.py` — Обновить команды
#### SaveToDatabaseCommand
- Вызвать `generate_embedding(text)` при сохранении
- Сохранить эмбеддинг в столбец `embedding`
- Обновить SQL-запрос: `INSERT INTO knowledge (name, text, embedding) VALUES (...)`

#### LoadFromDatabaseCommand
- Генерировать эмбеддинг для поискового запроса
- Выполнить семантический поиск: `ORDER BY embedding <=> %s LIMIT 5`
- Вернуть топ-N результатов с текстом

```sql
SELECT name, text FROM knowledge 
WHERE embedding IS NOT NULL 
ORDER BY embedding <=> %s 
LIMIT 5;
```

### 4. `requirements.txt` — Добавить зависимость
```
openai
```

### 5. `.env` — Добавить переменную (если нужно)
```
EMBEDDING_MODEL=text-embedding-3-small
```

## Порядок выполнения

1. **Добавить `openai` в `requirements.txt`**
2. **Создать `tools/embeddings.py`** — утилита генерации эмбеддингов
3. **Обновить `migrations/db_0000.py`** — добавить столбец `embedding`
4. **Обновить `tools/database.py`** — `SaveToDatabaseCommand` + `LoadFromDatabaseCommand`
5. **Перезапустить Docker** — `docker compose down -v && .\deploy.ps1`
