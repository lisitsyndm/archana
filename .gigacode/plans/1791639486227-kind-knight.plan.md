# План: Добавление аутентификации и привязки контекста в MessageService.Run

## Изменяемые файлы

1. **`core/context_root.py`** — добавить поле `User` типа `UserData`
2. **`core/message_service.py`** — основной файл для изменений

## Требования

- Метод `Run` должен запрашивать у пользователя логин и пароль
- Вызывать `_auth(username, password)` для получения `UserData`
- Получать `ContextRoot` из `ContextManager` по `user_id` (из `UserData.ID`)
- Передавать `ContextRoot` в `CommandProcessor` перед обработкой команд

## Изменения

### `core/context_root.py`

1. **Добавить импорт:**
   ```python
   from core.user_data import UserData
   ```

2. **Добавить поле `User`** в `__init__`:
   ```python
   self.User: UserData = None
   ```

### `core/message_service.py`

1. **Добавить импорт:**
   ```python
   from core.context_manager import ContextManager
   ```

2. **Изменить метод `Run`:**
   - Заменить `self.should_continue = True` на цикл с аутентификацией в начале
   - Запросить `username` и `password` через `input()`
   - Вызвать `self._auth(username, password)` → получить `UserData`
   - Получить `ContextRoot` через `ContextManager().get_context(user_data.ID)`
   - Установить `ctx_root.User = user_data` (сохранить пользователя в контексте)
   - Обновить `self.CommandProcessor.ctx_root` на полученный `ContextRoot`


3. **Добавить поле `self.CurrentUser: UserData = None`** в `__init__`

## Верификация

- Запустить `main.py`
- Убедиться, что запрашиваются логин и пароль
- Убедиться, что после ввода данные проходят обработку команд
