# План: RBAC (Role-Based Access Control) для CommandProcessor

## Концепция

- Каждая команда объявляет минимальную требуемую роль через параметр `required_role`
- Иерархия: `admin` имеет доступ ко всему, `user` — только к командам с `required_role = UserRoles.user`
- Проверка происходит в `CommandProcessor.process_command()` перед вызовом `command.exec()`
- При недостатке прав возвращается `CommandResult` с сообщением об отказе в доступе

## Изменяемые файлы

### 1. `core/command.py`

Добавить поле `required_role` в конструктор:

```python
def __init__(self, name: str = "", data_class = None, required_role: UserRoles = UserRoles.user):
    ...
    self.required_role = required_role
```

### 2. `core/command_processor.py`

2.1. Добавить метод `_executeCommand(command, context_root, data)`:

```python
def _executeCommand(self, command: Command, context_root, data: dict) -> CommandResult:
    """Проверяет права доступа и выполняет команду."""
    if context_root.User is not None and context_root.User.Roles != UserRoles.admin:
        if command.required_role != UserRoles.user:
            return CommandResult(f"Доступ к команде '{command.Name}' запрещён для вашей роли.")
    return command.exec(context_root, data)
```

2.2. В `process_command()` заменить `command.exec(...)` на `self._executeCommand(command, self.ctx_root, data)`

### 3. `tools/database.py` (и другие инструменты)

Команды, доступные только админу, получают `required_role=UserRoles.admin`:

```python
class LoadFromDatabaseCommand(Command):
    def __init__(self):
        super().__init__("Найди в БД", LoadFromDatabaseCommandParameters, required_role=UserRoles.admin)
```

## Итого изменений

| Файл | Что |
|------|-----|
| `core/command.py` | Добавить `required_role: UserRoles = UserRoles.user` |
| `core/command_processor.py` | Добавить проверку роли перед `command.exec()` |
| `tools/database.py` | Поставить `required_role=admin` для DB-команд |

## Верификация

1. Запустить `main.py`, войти как `user` → DB-команды должны отклоняться
2. Войти как `admin` → все команды работают
