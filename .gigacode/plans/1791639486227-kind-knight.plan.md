# План: Переписать process на LangGraph

## Структура графа

### State

```python
class ProcessState(TypedDict):
    text: str              # входящий текст
    callback: Callable     # callback для вывода результата
```

### Вершины

| Вершина | Описание |
|---------|----------|
| `exec_text_command` | Вызывает `self.process_command(state["text"])`. Callback передан в State. |
| `exec_plan_command` | Вызывает `plan.next()`, если команда есть — формирует текст и вызывает `process_command`. |

### Переходы

```
exec_text_command → exec_plan_command  (переход 1)
  Если planStatus == Started → exec_plan_command
  Иначе → END

exec_plan_command → exec_plan_command  (переход 2, цикл)
  Если planStatus == Started → exec_plan_command
  Иначе → END
```

## Изменяемые файлы

### `core/command_processor.py`

**1.** Переписать метод `process(text, callback)`:

```python
def process(self, text: str, callback: Callable[[CommandResult], None]):
    graph = self._build_graph()
    state: ProcessState = {"text": text, "callback": callback}
    graph.invoke(state)
```

**2.** Добавить/обновить `_build_graph()`:

```python
def _build_graph(self):
    if self._compiled_graph is None:
        graph = StateGraph(ProcessState)
        graph.add_node("exec_text_command", self._node_exec_text_command)
        graph.add_node("exec_plan_command", self._node_exec_plan_command)
        graph.set_entry_point("exec_text_command")
        graph.add_conditional_edges(
            "exec_text_command",
            lambda s: "exec_plan_command" if self.ctx_root.plan.planStatus == PlanStatus.Started else END,
        )
        graph.add_conditional_edges(
            "exec_plan_command",
            lambda s: "exec_plan_command" if self.ctx_root.plan.planStatus == PlanStatus.Started else END,
        )
        self._compiled_graph = graph.compile()
    return self._compiled_graph
```

**3.** Узлы графа:

```python
def _node_exec_text_command(self, state: ProcessState) -> ProcessState:
    self.process_command(state["text"])
    return state

def _node_exec_plan_command(self, state: ProcessState) -> ProcessState:
    if self.ctx_root.plan.planStatus == PlanStatus.Started:
        cmd_data = self.ctx_root.plan.next()
        if cmd_data is not None:
            new_text = f"/ {cmd_data.commandName} : {cmd_data.commandPayload}"
            self.process_command(new_text)
    return state
```

**4.** `process_command()` остаётся **без изменений**.

## Верификация

1. Запустить `main.py`
2. Ввести команду — обработается через `exec_text_command`
3. Команда с планом — цикл через `exec_plan_command` работает
4. RBAC сохраняется (внутри `process_command` → `_executeCommand`)
