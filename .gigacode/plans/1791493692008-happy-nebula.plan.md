# План: Вынесение LLM-взаимодействия в отдельный архитектурный слой

## Контекст

Сейчас LLM-зависимый код размазан по трём модулям:
- **`core/command_processor.py`** — `ChatOpenAI` для классификации и парсинга параметров (2 вызова)
- **`tools/unclassified.py`** — `ChatOpenAI` для произвольных запросов (1 вызов)
- **`core/embeddings.py`** — `OpenAI` SDK для эмбеддингов (1 вызов)

Каждый модуль самостоятельно создаёт клиент, читает конфиг из env-переменных, собирает метрики и токены.

## Цели

1. **Инкапсулировать** chat completions в `core/llm_client.py` и embeddings в `core/embedder_client.py`
2. **Разделить конфигурацию** — LLM и Embedder используют разные env-переменные
3. **Убрать дублирование** инициализации клиентов
4. **Сохранить** текущую observability (Prometheus-метрики, подсчёт токенов)
5. **Не сломать** существующие API — `CommandProcessor`, `UnclassifiedCommand`, `generate_embedding()` должны работать без изменений для вызывающего кода
6. **Обеспечить** возможность замены провайдера (mock/stub для тестов)

## Архитектурное решение

```
┌─────────────────────────────────────────────────┐
│  Layer: LLM Client (core/llm_client.py)         │
│                                                  │
│  LLMClient (singleton / DI)                      │
│  ├── invoke(prompt: str) -> str                  │
│  ├── invoke_with_parser(prompt: str, parser)     │
│  ├── _track_tokens(type, prompt, completion)     │
│  └── _track_duration(metric_name, duration)      │
│                                                  │
│  Конфигурация: LLM_APIKEY, LLM_URL, LLM_MODEL   │
└──────────────────┬──────────────────────────────┘
                   │ использует
┌──────────────────┴──────────────────────────────┐
│  Layer: Embedder Client (core/embedder_client.py)│
│                                                  │
│  EmbedderClient (singleton / DI)                 │
│  ├── generate_embedding(text: str) -> list[float]│
│  └── _track_tokens(type, prompt, completion)     │
│                                                  │
│  Конфигурация: EMBEDDING_APIKEY, EMBEDDING_URL,  │
│                EMBEDDING_MODEL из env             │
└──────────────────┬──────────────────────────────┘
                   │ использует
   ┌───────────────┼───────────────┐
   ▼               ▼               ▼
CommandProc.  Unclassified   Database
   │              │              │
   ▼              ▼              ▼
  Tools / Core layers (только бизнес-логика)
```

## Детали реализации

### 1. Новый файл: `core/llm_client.py`

```python
class LLMClient:
    """Клиент для LLM chat completions."""
    
    _instance: Optional[LLMClient] = None  # singleton
    
    # internals
    _chat: ChatOpenAI
    
    # class methods
    @classmethod
    def get_instance() -> LLMClient
    
    # chat operations
    def invoke(prompt: str) -> str                    # simple invoke, returns content
    def invoke_with_parser(prompt: str, parser) -> Any # invoke with output parser
    
    # internal helpers (private)
    def _track_tokens(type: str, prompt_tokens: int, completion_tokens: int)
    def _track_duration(metric_name: str, duration: float)
```

**Конфигурация (env):** `LLM_APIKEY`, `LLM_URL`, `LLM_MODEL`

### 2. Новый файл: `core/embedder_client.py`

```python
class EmbedderClient:
    """Клиент для генерации эмбеддингов."""
    
    _instance: Optional[EmbedderClient] = None  # singleton
    
    # internals
    _client: OpenAI
    
    # class methods
    @classmethod
    def get_instance() -> EmbedderClient
    
    # embedding operations
    def generate_embedding(text: str) -> list[float]
    
    # internal helpers (private)
    def _track_tokens(type: str, prompt_tokens: int, completion_tokens: int)
    def _track_duration(metric_name: str, duration: float)
```

**Конфигурация (env):** `EMBEDDING_APIKEY`, `EMBEDDING_URL`, `EMBEDDING_MODEL`

**Ключевые решения:**
- Два независимых singleton-клиента — каждый со своей конфигурацией
- `LLMClient.invoke()` — простой вызов, возвращает `str` (content)
- `LLMClient.invoke_with_parser()` — обёртка над chain `prompt | llm | parser`
- `EmbedderClient.generate_embedding()` — переносится из `core/embeddings.py`
- Метрики и подсчёт токенов — инкапсулированы внутри каждого клиента
